# Stylishranks

Stylishranks is a Minecraft plugin designed to manage and display player ranks with unique colors. It allows server owners and founders to assign ranks to players, with developers having the additional ability to assign developer ranks. The plugin supports a variety of ranks, including founder, owner, developer, moderator, senior-helper, helper, trail-helper, media, booster, loyal, vip, and mvp. Each rank is displayed with a unique color, and the plugin provides tab completion for easy command usage.

## Install

1. Download the Stylishranks plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. **Assign a Rank**:
   - Use the command `/rank set <player> <rank>` to assign a rank to a player.
   - Example: `/rank set Notch founder`

2. **Remove a Rank**:
   - Use the command `/rank remove <player> <rank>` to remove a rank from a player.
   - Example: `/rank remove Notch founder`

3. **Tab Completion**:
   - Press the Tab key after typing `/rank` to see available commands (`set`, `remove`).
   - Press the Tab key after typing `/rank set <player>` or `/rank remove <player>` to see the list of available ranks.
